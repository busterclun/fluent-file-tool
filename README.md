# Fluent 文件转换工具

Windows 桌面应用：通过本机 Ansys Fluent 将 `.cas.h5 / .dat.h5` 转换为传统 `.cas / .dat`，并提供独立的 Fluent 文件名规范化功能。

**当前正式版：v1.0.8 · Windows x64**

## 下载与启动

1. 在 [Releases](https://github.com/busterclun/fluent-file-tool/releases/latest) 下载 `FluentFileTool-1.0.8-Windows-x64.zip`。
2. 将压缩包完整解压到可写文件夹，双击 `Fluent文件转换工具.exe`。
3. 首次转换前，在“运行环境”填写本机 Fluent 安装目录、Python 程序路径和版本号。

桌面程序和转换脚本已打包。请将 EXE 与“运行组件”文件夹一起保留，无需下载源码即可运行。真实格式转换仍需要安装 Fluent、有效许可证，以及装有 PyFluent 和 NumPy 的外部 Python 环境。仅整理文件名无需 Fluent，也无需另外安装 Python。

## 两种用途

| 功能 | 入口 | 行为 |
|---|---|---|
| H5 转传统格式 | 转换工作台 | Fluent 读取原文件、写出传统 CAS/DAT、回读核验，输出保留各自源文件名，仅移除末尾 .h5 |
| 整理已有文件名 | 整理文件名 | 预览并规范化 CAS/DAT 名称，保留完整扩展名和前导零，不改写文件内容 |

示例：

```text
改名前
fuxian_fadhl-36.cas.h5-37.cas
fuxian_fadhl-36.cas.h5-37-02500.dat

改名后
fuxian_fadhl-02500.cas
fuxian_fadhl-02500.dat
```

规范化功能默认关闭，默认仅处理所选目录。必须检查预览并点击“确认改名”后才执行；重复时间步、配对歧义、扩展格式不一致或目标冲突会阻止整批执行。

## 验证范围

真实转换此前已在 Fluent 2024 R1、PyFluent 0.37.2、二维双精度环境验证。其他 Fluent 版本、三维和其他物理模型需要在目标环境验证。文件名规范化检查只针对名称和文件元数据，不代表读取了 Fluent 内部实际时间步。

应用在本机处理文件；公开下载包不含 CFD 数据、个人配置或运行日志。任务成功后显示分阶段完成反馈，失败时请查看日志详情。

无编号初始文件：在“整理文件名”勾选“将无编号配对作为初始帧”，确认初始编号（默认 0），检查预览后执行。支持传统格式和 H5；补零位数跟随后续文件，配对或编号冲突会阻止执行。

启动时自动检索 Fluent 安装位置和兼容 Python；在“运行环境”可重新检索或选择其他兼容组合，手动选择路径仍然可用。
